# 隐私政策

## 引言

AbcMall（阿帕次商城）深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们致力于维持您对我们的信任，恪守以下原则保护您的个人信息：权责一致原则、目的明确原则、选择同意原则、最少够用原则、确保安全原则、主体参与原则、公开透明原则等。

本隐私政策将帮助您了解我们收集、使用、存储、共享和保护您的个人信息的方式，请您在使用我们的产品和服务前仔细阅读并充分理解本政策。

## 我们收集的信息

### 1. 注册与账号信息

当您注册 AbcMall 账号时，我们会收集以下信息：

| 信息类型 | 具体内容 | 收集目的 |
|---------|---------|---------|
| 基本信息 | 手机号、用户名、密码 | 创建账号、身份验证 |
| 可选信息 | 昵称、头像、性别、生日 | 完善个人资料、个性化推荐 |
| 实名认证 | 真实姓名、身份证号（如需） | 实名验证、合规要求 |

### 2. 交易与订单信息

当您在平台购物时，我们会收集以下信息：

| 信息类型 | 具体内容 | 收集目的 |
|---------|---------|---------|
| 订单信息 | 订单号、商品信息、金额、下单时间 | 处理订单、发货、售后 |
| 收货信息 | 收货人姓名、手机号、收货地址 | 配送商品 |
| 支付信息 | 支付方式、支付金额、交易时间 | 完成支付、退款处理 |
| 发票信息 | 发票抬头、税号、发票接收邮箱 | 开具发票 |

**注意**：我们不会存储您的银行卡密码、支付密码等敏感信息，支付过程由第三方支付机构处理。

### 3. 设备与日志信息

当您使用 App 或网站时，我们会自动收集以下信息：

| 信息类型 | 具体内容 | 收集目的 |
|---------|---------|---------|
| 设备信息 | 设备型号、操作系统版本、设备标识符 | 适配设备、识别异常 |
| 日志信息 | IP 地址、浏览记录、搜索记录、访问时间 | 优化服务、安全风控 |
| 位置信息 | 粗略位置（基于 IP）、精确位置（需授权） | 配送时效估算、附近商品推荐 |

**位置信息说明**：精确位置信息仅在您授权后才会收集，您可以随时在系统设置中关闭位置权限。

### 4. 您主动提供的信息

- 评价、晒单内容
- 客服沟通记录
- 参与活动时填写的信息
- 反馈建议

## 我们如何使用信息

我们收集您的个人信息，主要用于以下目的：

### 1. 提供核心服务

- 账号注册、登录、身份验证
- 商品展示、搜索、推荐
- 下单、支付、发货、收货
- 售后、退款、客服服务

### 2. 优化和改善服务

- 分析用户使用习惯，优化产品功能
- 个性化推荐商品和活动
- 改进用户体验
- 统计分析、市场调研

### 3. 安全与风控

- 检测和防范欺诈、盗号等安全风险
- 保护账号安全
- 遵守法律法规要求
- 打击刷单、虚假交易等违规行为

### 4. 征得您同意的其他用途

- 向您推送营销信息（可随时取消订阅）
- 与合作伙伴联合活动（会明确告知并征得同意）

## 信息的共享与披露

我们承诺不会向任何第三方出售您的个人信息。仅在以下情况下，我们可能会共享您的信息：

### 1. 事先获得您的明确同意

- 您明确授权我们共享某些信息
- 您主动选择参与第三方活动

### 2. 必要的服务合作伙伴

为完成交易和提供服务，我们需要与以下合作伙伴共享必要信息：

| 合作方 | 共享内容 | 目的 |
|-------|---------|------|
| 物流公司 | 收货人姓名、电话、地址 | 配送商品 |
| 支付机构 | 订单号、金额、支付时间 | 完成支付和退款 |
| 商家/供应商 | 订单信息、收货信息 | 发货和售后 |
| 短信服务商 | 手机号、短信内容 | 发送验证码和通知 |

**所有合作伙伴均需遵守严格的保密协议，不得将信息用于其他用途。**

### 3. 法律要求

在以下情况下，我们可能会依法披露您的信息：

- 遵守法律法规或司法机关要求
- 保护用户或公众的人身财产安全
- 维护平台合法权益
- 应对安全事件和突发事件

## 信息的存储与安全

### 存储地点

- 您的个人信息均存储在中华人民共和国境内
- 我们不会向境外传输您的个人信息（法律法规另有规定或征得您同意的除外）

### 存储期限

- 我们仅在实现目的所必需的最短时间内保留您的个人信息
- 账号注销后，我们将在合理期限内删除或匿名化处理您的个人信息
- 法律法规有特殊要求的（如交易记录需保存 5 年），按法律规定执行

### 安全措施

我们采取以下措施保护您的个人信息安全：

1. **技术措施**：数据加密传输（HTTPS）、敏感信息加密存储、防火墙、入侵检测
2. **管理措施**：严格的权限控制、访问审计、安全培训、隐私保护制度
3. **应急预案**：数据泄露应急预案、定期安全演练

尽管我们采取了合理的安全措施，但互联网并非绝对安全，我们建议您妥善保管账号和密码。

## 您的权利

您对您的个人信息享有以下权利：

### 1. 访问权

您可以随时在"个人中心"查看您的账号信息、订单信息、收货地址等。

### 2. 更正权

如您的信息有误或发生变化，您可以随时修改：
- 个人资料（昵称、头像、生日等）
- 收货地址
- 密码
- 绑定的手机号

### 3. 删除权

您可以要求删除您的个人信息，包括：
- 删除收货地址
- 删除浏览记录
- 删除搜索历史
- 注销账号（账号注销后，个人信息将被删除或匿名化）

### 4. 撤回同意权

您可以随时撤回之前的授权同意：
- 关闭位置权限
- 关闭消息推送
- 取消订阅营销短信
- 注销账号

### 5. 注销账号

**注销路径**：我的 → 设置 → 账号安全 → 注销账号

**注销后果**：
- 账号注销后不可恢复
- 所有个人信息将被删除或匿名化
- 订单记录、积分、优惠券等将被清零
- 注销操作不可逆，请谨慎操作

**注销审核**：提交注销申请后，有 7 天冷静期，7 天后自动生效。期间可取消注销。

## 未成年人保护

- 我们非常重视未成年人的个人信息保护
- 若您是未满 14 周岁的未成年人，请在监护人的陪同下阅读本政策
- 未满 14 周岁的未成年人使用我们的服务，需征得监护人同意
- 如您是监护人，发现您的孩子未经同意注册账号，请联系我们，我们会及时删除相关信息

## Cookie 的使用

### 什么是 Cookie

Cookie 是网站存储在您浏览器中的小型文本文件，用于记住您的偏好设置、登录状态等信息。

### 我们使用 Cookie 的目的

- 记住登录状态，避免重复登录
- 记住您的偏好设置
- 分析网站访问情况，优化用户体验
- 购物车功能

### 管理 Cookie

您可以在浏览器设置中管理 Cookie：
- 清除 Cookie
- 禁用 Cookie（禁用后部分功能可能无法使用）
- 设置 Cookie 有效期
