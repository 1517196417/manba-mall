# 发票政策

## 政策概述

AbcMall（阿帕次商城）所有在售商品均可开具正规发票。本政策说明发票类型、开具方式、开票时效、换开发票等相关事项。

## 发票类型

### 1. 增值税电子普通发票（推荐）

- **适用对象**：个人消费者、小规模纳税人企业
- **法律效力**：与纸质发票具有同等法律效力，可用于报销、入账
- **优势**：开票快、不易丢失、可随时下载打印
- **格式**：PDF 格式，含发票专用章电子签章

### 2. 增值税专用发票

- **适用对象**：一般纳税人企业
- **抵扣功能**：可用于进项税额抵扣
- **开票条件**：需提供完整的一般纳税人资质信息
- **发票形式**：纸质专用发票，通过快递寄送

## 开票方式

### 下单时开具

提交订单时，在"发票信息"栏目中选择"需要发票"，填写发票抬头和税号（如需）。发票将在订单发货后 3~5 个工作日内开具。

### 收货后补开

下单时忘记勾选发票的，可在签收后 **30 天内** 申请补开发票。超过 30 天的订单不再支持补开。

补开路径：我的订单 → 找到对应订单 → 点击"申请发票" → 填写发票信息

## 开票须知

### 电子普通发票

| 项目 | 说明 |
|------|------|
| 开票内容 | 按实际购买商品名称开具，不可更改品类 |
| 开票金额 | 按实付金额开具，不含运费、优惠券抵扣部分 |
| 开票时间 | 订单发货后 3~5 个工作日 |
| 获取方式 | 订单详情页下载 / 发送至填写的邮箱 |
| 抬头类型 | 个人 / 企业（企业需提供税号） |

### 增值税专用发票

| 项目 | 说明 |
|------|------|
| 开票内容 | 按实际商品明细开具 |
| 开票金额 | 按实付金额开具 |
| 开票时间 | 订单签收后 7~10 个工作日 |
| 寄送方式 | 顺丰到付（订单满 1000 元包邮） |
| 所需信息 | 公司名称、税号、注册地址、注册电话、开户行、银行账号 |

**注意**：开具增值税专用发票前，请确认您的企业为一般纳税人资质。若因资质问题导致无法抵扣，平台不承担责任。

## 换开发票

如发票信息有误，可在收到发票后 **30 天内** 申请换开，换开需满足以下条件：

1. 原发票需退回（电子发票需确认未用于报销）
2. 换开前后的商品信息、金额、订单号需一致
3. 抬头类型不可变更（个人不可换为企业，普票不可换为专票）
4. 换开次数限一次

### 换开流程

1. 在订单详情中点击"申请换开发票"
2. 填写正确的发票信息
3. 提交审核（1~2 个工作日）
4. 审核通过后，原发票作废，开具新发票
5. 电子发票 2~3 个工作日可下载；纸质发票 5~7 个工作日寄出

## 发票与退换货

### 退货时的发票处理

- 申请退货时，需将发票一并退回
- 电子发票：系统自动冲红作废
- 纸质发票：需寄回发票原件，否则将从退款中扣除相应税费（通常为发票金额的 13%）
- 若发票已入账抵扣，需购买方先出具红字信息表后方可退款

### 换货时的发票处理

- 同款商品换货，原发票继续有效，无需重开
- 如换货后商品金额有差异，需退回原发票，按新金额重开

## 常见问题

**Q：发票为什么和商品不一起寄过来？**
A：根据税务规定，发票需在订单完成交易后才能开具。电子发票会在发货后 3~5 个工作日开具到您的账户中，可自行下载。

**Q：可以开办公用品、耗材这种笼统的名称吗？**
A：不可以。根据国家税务总局规定，发票必须按实际购买的商品明细开具，不能开具笼统的品类名称。

**Q：电子发票可以报销吗？**
A：可以。电子发票是国家税务总局认可的合法凭证，与纸质发票具有同等法律效力，可用于报销、入账、维权等。

**Q：一笔订单可以开多张发票吗？**
A：一笔订单只能开具一张发票。如果需要拆分开票，请分开下单。

**Q：发票开错了怎么办？**
A：请在收到发票 30 天内申请换开。如果是我方原因开错，换开的运费由平台承担；如果是您填写信息有误，运费需自行承担。
