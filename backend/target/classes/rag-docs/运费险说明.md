# 运费险说明

## 什么是运费险

运费险（全称为"退货运费险"）是由保险公司承保的一项增值服务。当消费者因个人原因发起 7 天无理由退货时，保险公司将赔付首重运费，降低消费者的退货成本。

## 运费险的作用

- **退货时赔付首重运费**：7 天无理由退货（非质量问题）产生的退货运费，由保险公司赔付首重（通常为 1 公斤以内）
- **自动理赔**：退款成功后 72 小时内自动到账，无需手动申请
- **降低退货成本**：尤其是小件商品，运费险基本可以覆盖退货运费

## 哪些商品有运费险

### 运费险覆盖的商品

- 大部分服装、鞋包、家居类商品默认赠送运费险
- 部分商家为提升服务质量，主动为全店商品购买运费险
- 商品详情页会标注"赠运费险"或"运费险"标识

### 运费险不覆盖的商品

- 生鲜食品、定制商品、虚拟商品
- 大件家具、家电（因运费过高，不在赔付范围内）
- 明确标注"不支持运费险"的商品
- 二手商品、拍卖商品

## 如何购买运费险

- **商家赠送**：大部分商品由商家免费赠送，下单时自动包含
- **消费者购买**：部分商品可在结算页自行购买，价格通常为 0.5~2 元/单
- **会员权益**：PLUS 会员每月可领取 5 张运费险抵扣券

## 赔付标准

| 地区 | 首重赔付金额 | 续重 |
|------|-------------|------|
| 同城（同一城市） | 8 元 | 不赔付 |
| 同省（省内） | 10 元 | 不赔付 |
| 跨省（华东/华北/华南） | 12 元 | 不赔付 |
| 偏远地区（新疆、西藏、青海、内蒙、甘肃、宁夏） | 20 元 | 不赔付 |

**说明**：
- 运费险只赔付首重（1 公斤以内），超出部分由消费者自行承担
- 实际运费低于赔付金额的，按实际运费赔付；高于赔付金额的，超出部分自理
- 同一订单仅赔付一次运费险
- 换货不享受运费险赔付

## 理赔流程

```
申请退货 → 寄回商品 → 商家确认收货 → 退款成功
                                              ↓
                                    保险公司自动审核（72小时内）
                                              ↓
                                        赔款到账
```

1. **正常退货**：在订单页面申请退货退款，按正常流程操作
2. **填写运单号**：退货时请在系统中填写快递单号（非常重要，没有单号无法理赔）
3. **等待退款**：商家收到商品后确认退款
4. **自动理赔**：退款成功后，保险公司会在 72 小时内自动审核并赔付
5. **查询到账**：赔款将退至您的原支付账户或 AbcMall 余额

## 理赔查询方式

- **路径**：我的订单 → 对应订单 → 退款详情 → 运费险理赔状态
- **到账查询**：我的 → 我的钱包 → 账单明细
- 如超过 72 小时仍未到账，请联系客服协助查询

## 不予理赔的情况

以下情况，运费险不予赔付：

1. **质量问题退货**：质量问题的退货运费由商家承担，不走运费险
2. **未填写退货运单号**：系统无法识别退货物流信息
3. **退货商品与订单不符**：退回的商品不是原订单商品
4. **多次拒收**：因消费者原因导致快递多次被拒收
5. **部分退货**：订单含多件商品，仅退其中一件的，按比例赔付
6. **超过 7 天退货期**：超出 7 天无理由退货期限的退货
7. **消费者承担的发货运费**：运费险只赔付退货的运费，不赔付发货运费
8. **使用顺丰、EMS 等高价快递**：按普通快递标准赔付，超出部分自理

## 常见问题

**Q：运费险的钱退到哪里？**
A：退回到您支付时使用的账户（微信/支付宝/银行卡），或者 AbcMall 账户余额，具体取决于支付方式。

**Q：我用了优惠券和积分，运费险按什么金额赔付？**
A：运费险赔付金额与订单金额无关，按退货地址和收货地址之间的首重运费标准赔付。

**Q：换货可以用运费险吗？**
A：不可以。运费险仅支持退货退款场景，换货不在赔付范围内。

**Q：一笔订单有两件商品，退一件怎么赔？**
A：部分退货时，运费险按该件商品的重量占比计算赔付金额。通常情况下按一次完整赔付处理，但具体以保险公司审核为准。

**Q：为什么我退货了却没有运费险赔付？**
A：可能的原因：① 该商品没有运费险；② 退货原因是质量问题（运费由商家承担）；③ 未填写运单号；④ 还在 72 小时审核期内；⑤ 超出理赔范围。
