# 配送时效说明

## 配送概述

AbcMall（阿帕次商城）与多家主流快递公司合作，为您提供快速、可靠的配送服务。本说明详细介绍发货时效、配送时效、配送范围、配送费用等相关信息。

## 发货时效

### 普通商品

| 下单时间 | 发货时间 |
|---------|---------|
| 当日 16:00 前下单 | 当日发货 |
| 当日 16:00 后下单 | 次日发货 |
| 周五 16:00 后 ~ 周日 | 周一发货 |

- 发货时效以支付成功时间为准
- 预售商品、定制商品以商品详情页标注的发货时间为准
- 节假日发货时间可能顺延，具体以公告为准

### 特殊商品

| 商品类型 | 发货时效 | 说明 |
|---------|---------|------|
| 现货商品 | 24 小时内 | 大部分商品 |
| 预售商品 | 按页面标注 | 通常 7~30 天内发货 |
| 定制商品 | 3~15 个工作日 | 按定制复杂度不同 |
| 大件家具 | 7~15 个工作日 | 含送货上门和安装服务 |
| 生鲜食品 | 当日/次日 | 冷链配送，需及时签收 |
| 虚拟商品 | 即时到账 | 充值卡、电子券等 |

### 影响发货时效的因素

以下情况可能导致发货延迟：

1. **大促期间**（618、双 11 等）：订单量激增，发货可能延迟 1~3 天
2. **不可抗力**：暴雨、暴雪、台风、地震等自然灾害
3. **政策管制**：重大活动期间的交通管制、快递管制
4. **库存不足**：部分热销商品可能临时缺货，补货后优先发出
5. **地址异常**：地址不详细或无法送达的地区，客服会联系确认

## 配送时效

### 中国大陆地区

| 配送区域 | 普通快递 | 顺丰速运 | 当日达 |
|---------|---------|---------|--------|
| 同城（同一城市） | 1~2 天 | 次日达 | 支持（部分城市） |
| 江浙沪皖 | 1~2 天 | 次日达 | — |
| 华东/华北/华南主要城市 | 2~3 天 | 次日达 | 部分城市支持 |
| 中西部省会城市 | 3~4 天 | 1~2 天 | — |
| 一般地级市 | 3~5 天 | 2~3 天 | — |
| 县城及乡镇 | 4~6 天 | 3~4 天 | — |
| 偏远地区（新疆、西藏、青海、内蒙等） | 7~15 天 | 5~7 天 | — |

**配送时效说明**：
- 时效为预估时间，从发货次日起算
- 时效为工作日，不含周末和法定节假日
- 偏远地区可能额外增加 2~5 天
- 如遇恶劣天气、交通管制等不可抗力，时效可能延长

### 港澳台及海外

- 港澳台地区：支持顺丰快递，时效 3~7 天，运费较高
- 海外地区：暂不支持直接配送，建议使用转运服务

## 配送状态说明

| 状态 | 含义 |
|------|------|
| 待发货 | 订单已支付，等待商家发货 |
| 已发货 | 商品已发出，快递正在运输中 |
| 派送中 | 快递已到达目的地城市，正在派送 |
| 已签收 | 商品已成功签收 |
| 派送失败 | 因地址不详、无人接听等原因派送失败，快递员会再次联系 |
| 已退回 | 商品因拒收、地址错误等原因被退回 |

## 签收须知

### 正常签收

- 请在快递员派送时保持电话畅通
- 建议本人签收，如本人无法签收，可委托他人代收
- 代收视为本人签收

### 验货签收

- **贵重商品（数码、家电等）**：建议当面验货，确认商品完好后再签收
- **如有破损**：请立即拒收，并联系客服说明情况
- **签收后发现问题**：请在 24 小时内联系客服，并提供商品破损照片

### 拒收

如商品有以下情况，您可以拒收：

1. 外包装明显破损、变形
2. 商品与订单不符
3. 商品有明显使用痕迹
4. 缺少配件或发票

拒收后请及时联系客服，我们会安排重新发货或退款。

## 常见问题

**Q：为什么我的订单还没发货？**
A：可能的原因：① 下单时间在 16:00 之后，次日发货；② 商品是预售款，按预售时间发货；③ 大促期间订单量大，延迟 1~3 天；④ 库存不足，正在补货。可以在订单详情中查看预计发货时间。

**Q：可以指定快递公司吗？**
A：系统会根据商品类型和收货地址自动选择最优快递，暂不支持指定快递。如有特殊需求（如必须顺丰），可联系客服补差价安排。

**Q：快递显示已签收但我没收到怎么办？**
A：先检查是否被门卫、前台、快递柜或邻居代收。如确实未收到，请在 24 小时内联系客服，我们会协助您联系快递核实。

**Q：可以修改收货地址吗？**
A：订单未发货前可以修改地址。已发货的订单无法修改地址，请联系快递员协商改派，可能产生额外运费。

**Q：为什么同城也要 2 天？**
A：快递需要经过"取件 → 分拣 → 运输 → 派送"等环节，同城通常是次日达，部分区域可能当天送达。

**Q：配送超时了有补偿吗？**
A：如果超过承诺配送时效 3 天以上，您可以联系客服申请 5~20 元不等的优惠券补偿。因不可抗力导致的延迟除外。
