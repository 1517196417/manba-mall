# 7天无理由退换货政策

## 政策概述

AbcMall（阿帕次商城）承诺，自商品签收之日起 **7 天内**，符合条件的商品可享受"无理由退换货"服务。消费者无需说明理由，即可申请退货或换货。本政策依据《中华人民共和国消费者权益保护法》《网络购买商品七日无理由退货暂行办法》制定。

## 适用范围

### 支持 7 天无理由退货的商品

- 服装鞋帽、箱包配饰
- 数码配件、手机电脑周边
- 家居用品、厨具餐具
- 图书文具、办公用品
- 美妆护肤、个护清洁（未拆封）
- 小家电、智能设备（未激活）

### 不适用 7 天无理由退货的商品

以下商品一经售出，非质量问题不支持无理由退货：

1. **消费者定作的商品** — 如定制手机壳、刻字礼品、定制尺寸的家具等
2. **鲜活易腐的商品** — 如生鲜水果、鲜花绿植、食品饮料等
3. **在线下载或消费者拆封的音像制品、计算机软件等数字化商品** — 如电子卡密、充值码、游戏道具、软件激活码等
4. **交付的报纸、期刊**
5. **拆封后易影响人身安全或生命健康的商品** — 如内衣裤、袜子、口罩、美瞳、隐形眼镜、计生用品等
6. **一经激活或试用后价值贬损较大的商品** — 如已激活的手机、电脑、智能手表等数码产品
7. **服务类商品** — 如会员充值、虚拟服务、旅游门票、酒店预订等

## 退货条件

申请 7 天无理由退货，需同时满足以下条件：

1. **时间要求**：自签收之日起 7 天内（含第 7 天，以物流签收时间为准）
2. **商品完好**：商品本身、配件、包装、吊牌、说明书等完好齐全，不影响二次销售
3. **赠品齐全**：如订单包含赠品，需一并退回；若赠品遗失或损坏，需按赠品价值折价扣除
4. **发票齐全**：如已开具发票，需将发票一并退回；若发票遗失，需扣除相应税费

### "商品完好"判定标准

| 商品类别 | 完好标准 |
|---------|----------|
| 服装鞋帽 | 吊牌、洗唛完整，无穿着痕迹，无污渍、水洗、变形 |
| 数码电器 | 包装完好，配件齐全，未激活，无人为损坏，开机不超过 1 小时 |
| 美妆个护 | 外包装未拆封，塑封膜完好，未使用 |
| 家居用品 | 包装完好，未使用，无污渍、无损坏 |
| 图书文具 | 书籍未翻阅、无折痕，文具未使用、包装完好 |

## 退货流程

1. **申请退货**：在"我的订单"中找到对应订单，点击"申请退货"，选择退货原因
2. **商家审核**：商家将在 24 小时内审核退货申请
3. **寄回商品**：审核通过后，请在 7 天内将商品寄回指定地址（运费承担见下文）
4. **商家验货**：商家收到商品后 48 小时内完成验货
5. **退款到账**：验货通过后，退款将在 1~3 个工作日内原路退回

## 运费承担

| 退货原因 | 运费承担方 | 说明 |
|---------|-----------|------|
| 质量问题、发错货、漏发货 | 商家承担 | 需先垫付运费并保留凭证，商家确认后返还 |
| 7天无理由退货（非质量问题） | 消费者承担 | 若购买了运费险，可由运费险赔付首重 |

**注意**：到付件一律拒收。请使用普通快递寄回，请勿使用顺丰、EMS 等高价快递（质量问题除外）。

## 换货说明

- 7 天内可申请换货，换货仅限同款同规格商品更换一次
- 换货产生的运费，非质量问题由消费者承担
- 如同款商品已售罄，可申请退货退款

## 常见问题

**Q：7天是从什么时候开始算？**
A：从快递签收的次日 0 点开始计算，满 7×24 小时为截止时间。

**Q：商品已经拆封了还能退吗？**
A：拆封本身不影响退货，关键看商品是否"完好"。如果只是拆开了包装但商品未使用、配件齐全，通常可以退。但有塑封膜的商品（如美妆、软件）拆封后一般不能退。

**Q：退货时寄错地址了怎么办？**
A：请立即联系客服，我们会协助您联系快递改地址。因寄错地址产生的额外运费由消费者承担。

**Q：退款为什么比实付金额少？**
A：可能扣除了以下费用：赠品折价费、发票税费、运费（非质量问题）、使用的优惠券/积分等额扣除。具体明细可在退款详情中查看。
