# 退款政策

## 政策概述

AbcMall（阿帕次商城）致力于为消费者提供便捷、透明的退款服务。本政策详细说明各类退款场景的处理规则、退款时效和退款路径，保障消费者的合法权益。

## 退款场景与规则

### 1. 退货退款

- **适用条件**：符合 7 天无理由退货或质量问题退货的订单
- **退款金额**：商品实付金额（不含运费，运费承担见《7天无理由退换货政策》）
- **退款时机**：商家收到退回商品并验货通过后发起退款
- **赠品处理**：赠品需一并退回，否则按赠品市场价值从退款中扣除
- **优惠券/积分**：使用优惠券抵扣的部分不予退还现金；使用积分抵扣的部分，积分将在退款成功后 24 小时内退回账户

### 2. 仅退款（不退货）

以下情况可申请仅退款，无需寄回商品：

- 商家发错货、漏发货，且消费者无需换货
- 商品存在轻微质量问题，消费者同意留用并接受部分退款
- 虚拟商品（如充值失败、卡密错误）
- 商家超时未发货（超过承诺发货时间 48 小时）

### 3. 未发货退款

- 订单状态为"待发货"时，消费者可随时申请退款
- 商家需在 24 小时内审核，审核通过后立即退款
- 若商家超时未处理，系统将自动同意退款

### 4. 取消订单退款

- 未付款订单：取消后无退款
- 已付款未发货：取消后全额退款，1~3 个工作日到账
- 已发货：无法直接取消，需拒收后申请退货退款

## 退款路径

退款一律按"原路返回"原则，退回到支付时使用的账户：

| 支付方式 | 退款路径 | 到账时效 |
|---------|---------|---------|
| 微信支付 | 退回原微信账户（零钱/银行卡） | 1~3 个工作日 |
| 支付宝 | 退回原支付宝账户（余额/银行卡） | 1~3 个工作日 |
| 银行卡 | 退回原支付银行卡 | 3~7 个工作日 |
| 平台余额 | 退回 AbcMall 账户余额 | 实时到账 |
| 组合支付 | 按各支付方式的支付比例分别退回 | 按各渠道时效 |

**注意**：银行卡退款到账时间取决于银行处理速度，节假日可能顺延。

## 退款金额计算

退款金额 = 商品实付金额 - 应扣除费用

### 应扣除的费用包括

| 扣除项目 | 扣除标准 | 适用场景 |
|---------|---------|---------|
| 运费 | 实际支付的运费金额 | 非质量问题的 7 天无理由退货 |
| 赠品折价 | 赠品的市场售价 | 赠品遗失、损坏或未退回 |
| 税费 | 发票金额 × 税率（通常 13%） | 发票遗失或无法退回 |
| 折旧费用 | 商品价格 × 折旧率 | 商品已使用但仍可退货的特殊情况 |
| 优惠券抵扣 | 对应优惠金额 | 不退还现金，优惠券是否返还视券类型而定 |

## 退款状态说明

| 状态 | 含义 |
|------|------|
| 待审核 | 退款申请已提交，等待商家审核 |
| 审核通过 | 商家同意退款，等待退款处理 |
| 退款中 | 财务已处理，等待支付渠道到账 |
| 退款成功 | 款项已成功退回支付账户 |
| 退款失败 | 退款被退回（如银行卡注销），需联系客服重新处理 |
| 已拒绝 | 商家拒绝退款申请，可申请平台介入 |

## 特殊情况处理

### 部分退款

订单含多件商品时，可对单件商品申请退款，退款金额按该商品的实付金额计算。

### 重复支付

因网络原因导致重复支付的，系统会在 24 小时内自动将重复支付的款项原路退回。

### 退款失败

若因银行卡注销、账户冻结等原因导致退款失败，请联系客服提供新的收款账户，我们将在 3 个工作日内重新处理。

## 常见问题

**Q：为什么退款金额和我付的钱不一样？**
A：可能扣除了运费、赠品折价、税费等。具体可在"退款详情"中查看扣款明细。

**Q：退款已经成功了，但我没收到钱？**
A：退款成功是指平台已将款项提交给支付渠道，实际到账需要 1~7 个工作日，具体取决于支付方式。如果超过 7 个工作日仍未到账，请联系客服。

**Q：使用优惠券的订单退款后，优惠券会返还吗？**
A：未使用且在有效期内的优惠券会返还；已过期的优惠券不返还；特殊活动优惠券（如新人券、限时券）不返还。

**Q：我可以要求退到其他账户吗？**
A：为保障资金安全，退款必须原路返回支付账户，不支持更改退款路径。
